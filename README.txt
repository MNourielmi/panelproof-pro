PANELPROOF PRO v1.0 — OFFLINE COMMISSIONING PACK BUILDER

START: Double-click index.html. Works in modern Chrome, Edge, or Firefox without installation or internet.

USE: Enter project details, mark each check Pass / Fail / N/A / Blocked / Not tested, record evidence, add custom checks. Click Print / Save PDF to produce a handover report. Export JSON to save a portable backup; Import JSON to reopen it.

SAFETY: This is a documentation aid, not an electrical safety procedure or regulatory compliance certification. Qualified personnel must review applicable codes, approved drawings, test methods, and sign-off requirements.

COMMERCIAL: This package is an original MVP and can be customized for clients. Validate requirements, test on target browsers, and establish licensing/terms before selling. No third-party runtime dependencies.

VERSION 1.1: New project button and issues CSV export added. Always export JSON before clearing browser storage or starting a new project.

V1.2: Click Load sample demo for an illustrative project (replaces current data). Export full register CSV for spreadsheet review. Sample results are not real tests.

V1.4 READINESS: The readiness banner checks documentation completeness only. It is not a safety certification or release authorization.
